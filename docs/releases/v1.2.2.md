# v1.2.2 — Manifest version fix

The manifest's `Version` field had been stuck at the v0.1 placeholder since day one; the Stream Deck UI's plugin-info panel was lying about which version was installed.

- **`manifest.json` Version** bumped `0.1.0.0` → `1.2.2.0`. From here on the manifest version tracks shipping 1:1 (`{major}.{minor}.{patch}.0` — the fourth component reserved for rebuild numbers within a patch).
- **Plugin description rewritten** to reflect the v1.2 feature set (thermals + fans + power; tap for slide, long-press for VU meter). Was still the v1.0 wording.
- **Release checklist** added to the top of `CHANGELOG.md` — three steps for every close-out (bump manifest, append release notes, rebuild + restart). Catches the drift class of bug.

No code changes; manifest + docs only. Tests unchanged at 86 Swift + 81 TS = 167.
