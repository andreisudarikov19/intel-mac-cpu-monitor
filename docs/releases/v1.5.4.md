# v1.5.4 — Logarithmic Disk I/O scale

The Disk I/O key's read/write meter barely moved during everyday disk activity — an app install or an SD-card photo import lit a single segment for a second and then went dark.

- **Root cause**: the scale was linear 0–1 GB/s, so the first segment needed ~56 MB/s. Real workloads are bursty and sit in the tens-to-hundreds of MB/s, which barely registers on that range.
- **Change**: the meter and graph now use a logarithmic 1 MB/s – 3 GB/s scale — each segment is ~2.4× the one below. Idle (≤ 0.3 MB/s) stays dark; a ~90 MB/s photo import lights 5 of 9 segments; only a near-full-speed internal SSD transfer reaches the top. The 3 GB/s ceiling is the measured sequential speed of the reference iMac 27" 2020 SSD.
- **Colours**: re-cut for the new scale — 4 green, 2 yellow, 2 orange, 1 red segment, with the footer colour matching the topmost lit segment.
