# v1.3.1 — Hide slider in "Plugin default" mode

UI consistency polish on top of v1.3.0. The global-default slider was exposed in every PI, which let users accidentally adjust the plugin-wide value while they thought they were configuring one tile.

- **Global-default slider removed** from every PI. The plugin-wide default now stays at the hard-coded `SAMPLE_COUNT_DEFAULT` (30).
- **PI shows the per-tile slider only when scope = "This key only"**. In "Plugin default" mode, only the scope dropdown is visible.
- **Known limit**: no UI for changing the plugin-wide default. Per-tile override is the only adjustment path; a future "Set as plugin default" button would close this gap if needed.

No code outside the PI HTMLs. 183 tests unchanged.
