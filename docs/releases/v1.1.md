# v1.1 — Slide view + palette overhaul

Second view mode and a vibrant palette. No new sensor types.

- **Slide view** added: tap any key to flip from graph to a dark-bg card with a thick band-colored frame around the entire key (rounded rect inset 9 px, `rx=14`, stroke 7.5 px — concentric with Stream Deck's ~23 px bezel curve). Header white, value in band color, no graph. Persists per-key.
- **Palette switched** from macOS dark system colors to iPhone-StandBy-inspired vivid set derived from a single HSL anchor (S=79 %, L=58 %): cold `#3FBEE9`, cool `#42E84A`, warm `#E8DA42`, hot `#E88E42`, critical `#E84258`. All bands feel like siblings.
- **New "cold" band** (cyan) — applies only to the ambient air profile, threshold ≤ 20 °C.
- **Per-sensor `MetricProfile`** type — `{ range, coldMax?, coolMax, warmMax, hotMax }` so each sensor gets its own Y-axis range and band thresholds.
- **Graph refinements**: header font 16 → 26 px (matches slide), sparkline stroke 1.6 → 4.5 px, graph zone 50 % → 58 % of canvas, 7 px top margin.
- **History tuning**: buffer 60 → 45 samples, visible window 60 → 30. 5 px/sample on the 144 px canvas — each tick is a distinct mark.
- **Per-core probe widened** from 9 candidate keys to 16 (each casing) — picks up `TC9c` on 10-core CPUs.

111 tests green (53 Swift + 58 TS).
