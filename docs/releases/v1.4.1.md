# v1.4.1 — Left-aligned slide, dual-stream Disk I/O

UX polish on the v1.4.0 additions.

- **Uptime slide left-aligned**. Header "UPTIME" and the three duration lines all start at x=26 (`text-anchor="start"`) — data-sheet look instead of a centered banner. Every multi-line slide left-aligns by extension; future text-rich metrics (load average, battery state) inherit the same treatment.
- **Disk I/O dual-stream** — read and write now tracked as independent streams in every view mode:
  - **Graph view**: two sparklines together. Read uses the peak band color; write uses cyan `#3FBEE9` (the v1.1 "cold" color) for contrast.
  - **Slide view**: two left-aligned lines: `↓ 12.0 MB/s` (read) and `↑ 1.5 MB/s` (write).
  - **Meter view**: two columns side-by-side (52 px wide, 12 px gap, 14 px outer margins). Both share the same band gradient; each lights up independently. Compact footers `12M` / `1.5M` via the new ultra-compact byte formatter.
- **Subscription** gains optional `historyB: History`; **Hub** special-cases `diskIO` push to both buffers; **RenderInput** gains `samplesB` / `rawValueB` / `valueTextB` / `streamBColor` for any future two-stream metric; **`renderMeter`** refactored to loop over a column-spec array — single- and dual-column paths share the same rendering code.

208 tests green (86 Swift + 122 TS).
