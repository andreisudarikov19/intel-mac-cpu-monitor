# v1.2 — 8 new sensors, meter view, gesture model

Expanded sensor coverage, a third view mode, and unified press gestures.

- **8 new actions**: Air Temp (`TA0P`/`TA1P`/`TaLP`/`TaRF`), RAM Temp (`Ts0S`/`TM0P`/`Tm0P`/`TMA0`/`TMB0`), SSD Temp (`TH0A`/`TH0B`/`TH0C`/`TH0F`/`TH0x`/`TH1A`), Chipset Temp (`TN0D`/`TN0H`/`TN0P`/`Tp0P`), Wi-Fi Temp (`TW0P`), Thunderbolt Temp (`TI0P`/`TI1P`/`TTLD`/`TTRD`), CPU Power, GPU Power. Each with its own SMC key preference list, profile, PI HTML and icons.
- **Meter view** (80s VU column): 9 horizontal bars stacked vertically, ~8.4 px tall × 116 px wide, 2 px gap. Per-segment color is fixed by position (cool at bottom, critical at top); lit segments full opacity, unlit at 0.18. Works on every sensor type — temperature, fan, and power all map onto the same band gradient.
- **Gesture model**: short tap (< 600 ms) toggles graph ↔ slide; long press (≥ 600 ms) toggles graph ↔ meter. Gestures are independent — a slide can long-press to meter, a meter can long-press back to graph.
- **`TempProfile` → `MetricProfile`** (alias kept for back-compat): same shape, now covers temperature *and* power. 8 temperature profiles + 2 power profiles (CPU 0–125 W, GPU 0–150 W; bands tuned against Intel Mac TDPs with the 10-core 27" iMac at 125 W TDP as reference for full-scale).
- **Power decoder**: new `Decoders.decodePower(b0..b3, dataType)` dispatches `flt ` / `sp78` / fallback. NaN/Inf → nil. Catalog rejects values ≥ 1 kW as decode error.
- **Wire protocol additions** to `ReadingEvent`: `ambient`, `ram`, `ssd`, `chipset`, `wifi`, `thunderbolt`, `cpuPower`, `gpuPower` (all optional numbers).

162 tests green (81 Swift + 81 TS).
