# v1.3.0 — Sample-window configurability

The graph's sample window was hard-coded to 30 samples (30 s of history). Users can now pick the value — globally for the plugin, or per-tile as an override.

- **Sample-count slider** in every PI: range 15–60 samples (= 15–60 s at 1 Hz), step 5.
- **Scope dropdown**: "Plugin default (all keys)" vs "This key only". Default is plugin-default, so the slider's value applies globally; switching to per-tile treats it as an override that shadows the global default for one key.
- **Dynamic buffer resize**: each subscription's history ring buffer is sized at `ceil(visible × 1.5)`, keeping ~50 % extra samples in reserve for a future zoom-out feature. Default 30 → buffer 45; min 15 → 23; max 60 → 90.
- **`History.resize`** preserves the most recent samples that fit. Shrinking drops oldest; growing keeps everything and lets new samples fill the rest.
- **Settings additions**: new `GlobalSettings.defaultSampleCount`, per-action `Settings.sampleCount` (used iff `sampleScope === "tile"`), per-action `Settings.sampleScope`.

Existing tiles inherit the plugin default 30 — no visible change for any user who doesn't open a PI.
