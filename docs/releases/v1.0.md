# v1.0 — Initial release

Stream Deck plugin for Intel Macs showing live CPU temperatures, GPU temperature, and fan speed.

- **Four actions**: CPU Core Temp (per-core picker), CPU Temp (mean of detected cores with package-key fallback chain `TCAD` → `TC0F` → `TC0D` → `TC0E` → `TC0H` → `TCXC` → `TC0P`), GPU Temp, Fan Speed (per-fan picker).
- **Architecture**: Node/TypeScript plugin spawns a Swift helper (`smcreader`) that reads AppleSMC via IOKit and streams JSON Lines on stdout at 1 Hz. Plugin supervises the helper with auto-restart, stale-watch, and Apple Silicon detection.
- **Visualization**: 144 × 144 keys with label + value (top) and a 60-sample sparkline (bottom). macOS dark-mode palette; four color bands (cool / warm / hot / critical) classified per reading.
- **Decoder bug-fixed vs Fanny**: original Fanny code uses byte-0-only for all temperatures; v1.0 dispatches by SMC dataType (`sp78` / `ui8` / `flt`) so modern T2 Macs read correctly (Fanny would report 91 °C for what's actually 45.3 °C).
- **Distribution**: GitHub releases, sideload-only. Helper unsigned — README documents the one-time `xattr -dr com.apple.quarantine` workaround. Marketplace deferred.

103 tests green (53 Swift + 50 TS).
